02 Navigation & Basics › 
enable                        ! Enter privileged EXEC mode
configure terminal            ! Enter global config mode (short: conf t)
exit                          ! Go back one level
end                           ! Go back to privileged EXEC
do show run                   ! Run show commands from any config mode
no <command>                  ! Negate / undo any command
?                             ! Context-sensitive help
show run | include <keyword>  ! Filter running config output
show run | section ospf       ! Show only OSPF section of config

Tab autocomplete  |  Ctrl+C cancel  |  Ctrl+Z back to #  |  ↑ previous command

06 Routing ›
Static Routes
ip route 192.168.2.0 255.255.255.0 192.168.1.2     ! Via next-hop IP
ip route 192.168.2.0 255.255.255.0 GigabitEthernet0/1 ! Via exit interface
ip route 192.168.2.0 255.255.255.0 192.168.1.2 115 ! Floating static (AD 115)
Default Route
ip route 0.0.0.0 0.0.0.0 203.0.113.1   ! Send everything unknown here
OSPF
router ospf 1
 router-id 1.1.1.1
 network 192.168.1.0 0.0.0.255 area 0   ! Wildcard mask — NOT subnet mask
 passive-interface GigabitEthernet0/0   ! No hellos to end devices
 default-information originate          ! Inject default route into OSPF
💡 Wildcard mask = inverse of subnet mask

/24 → 0.0.0.255  |  /30 → 0.0.0.3  |  /32 → 0.0.0.0

Verify OSPF
show ip ospf neighbor     ! Must show FULL state
show ip ospf interface
show ip route ospf        ! Routes marked with O
show ip ospf database

11 ACLs (Access Control Lists) ›
💡 ACL Rules

Processed top-down — first match wins. Implicit deny any at the bottom. Put specific rules before general rules. Standard ACLs close to destination, extended close to source.

Standard ACL (source IP only)
access-list 10 permit 192.168.10.0 0.0.0.255
access-list 10 deny any

interface GigabitEthernet0/1
 ip access-group 10 out
Extended ACL (src, dst, protocol, port)
ip access-list extended WEBSERVER-FILTER
 permit tcp any host 10.10.50.10 eq 443
 permit tcp any host 10.10.50.10 eq 80
 deny ip any any log

interface GigabitEthernet0/0
 ip access-group WEBSERVER-FILTER in
Common Ports
PortProtocol
eq 80HTTP
eq 443HTTPS
eq 22SSH
eq 23Telnet
Verify
show access-lists
show ip interface Gi0/0

17 Saving & Managing Config › 
write memory                        ! Save config (short: wr)
copy running-config startup-config  ! Same as above
show running-config                 ! Current config (RAM)
show startup-config                 ! Saved config (NVRAM)
erase startup-config                ! Wipe saved config
reload                              ! Reboot device
⚠️ Save from # mode only

write memory must be run from privileged EXEC (#), not config mode. Running it inside (config)# throws an invalid input error.

19 Debug Commands ›
⚠️ Use carefully

Debug outputs can flood the console and impact performance. Always run undebug all when finished.

debug ip ospf events
debug ip ospf hello
debug ip routing
debug ip nat
debug ip dhcp server events
debug ip icmp

undebug all              ! Turn off ALL debug — do this when done
terminal monitor         ! Enable debug on VTY sessions
terminal no monitor
20 Troubleshooting Cheat Sheet ›
Layer-by-Layer Approach
LayerCheckCommand
L1 – PhysicalIs the port up?show ip interface brief — look for up/up
L2 – Data LinkCorrect VLAN? Trunk?show vlan brief, show interfaces trunk
L3 – NetworkCorrect IP? Route exists?show ip route, ping
L4+ – TransportACL blocking traffic?show access-lists — check hit counts
Can't ping between VLANs
show ip interface brief        ! Sub-interfaces up/up?
show ip route                  ! Routes for both subnets?
show interfaces trunk          ! Trunk set up?
! Check encapsulation dot1Q VLAN-ID matches exactly
OSPF neighbour not FULL
show ip ospf neighbor          ! What state? INIT? 2WAY? EXSTART?
show ip ospf interface         ! Same area? Same timers? Passive?
! Check: same subnet, same area, not passive, no ACL blocking
NAT not translating
show ip nat translations       ! Any entries?
! ip nat inside on LAN? ip nat outside on WAN?
! Does ACL match inside traffic?
debug ip nat                   ! Watch live
DHCP clients not getting IP
show ip dhcp pool
show ip dhcp binding
! ip helper-address configured if client on different subnet?
! Exclusion covering entire range?
show run | section dhcp
